1. The rules (a page, editable)

Each gate is a truth table over facts: a regex, a JSON shape, "every number occurs in the input", "every date occurs in the input". pass is arithmetic over 0 and 1: * is AND. after 3: stop caps the tries.

A refusal is "no answer", never a guess handed on. The gate never sees the right answer; it sees the input and the answer.
The same gate, run as the checker in an agent pipeline on a 3B local model, cut wrong answers from 68 to 4 percent at a quarter of the tokens; on a 7B model the wrong-answer cut held and the token saving did not. Both numbers are in the benchmark folder, with the bars that were written before the runs.
